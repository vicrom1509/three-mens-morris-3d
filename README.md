# Три Мельницы 3D (Three Men's Morris 3D) — iOS PWA для iPhone и GitHub Pages

Готовый пакет веб-приложения **Progressive Web App (PWA)** для установки игры **«Три Мельницы 3D»** на iPhone (iOS / iPadOS) через **GitHub Pages** без компьютера Mac и без платного аккаунта разработчика Apple.

## Состав пакета

| Файл | Назначение |
| :--- | :--- |
| `index.html` | Главный файл игры (автоматически открывается по короткой ссылке GitHub Pages), с поддержкой Safe Area (`Dynamic Island` / челки iPhone), офлайн-стилями и регистрацией Service Worker |
| `three_mens_morris_3d.html` | Копия `index.html` для совместимости с прямыми ссылками |
| `manifest.json` | Манифест веб-приложения (`display: standalone`, портретная ориентация, темная тема `#0d0907`, иконки) |
| `sw.js` | Service Worker для кэширования игры и 3D-движка в памяти iPhone (позволяет запускать игру без интернета) |
| `apple-touch-icon.png` | Фирменная иконка для домашнего экрана iPhone (`180x180`, без прозрачных углов по стандарту Apple Human Interface Guidelines) |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `favicon.png` | Иконки высокого разрешения для всех экранов и браузеров |
| `.nojekyll` | Служебный файл для GitHub Pages, чтобы файлы публиковались мгновенно без обработки сборщиком Jekyll |

## Шаг 1. Публикация на GitHub Pages (за 2 минуты)

1. Зайдите на [github.com](https://github.com/) в свой аккаунт и нажмите **New repository** (кнопка `+` в правом верхнем углу).
2. В поле **Repository name** введите, например: `three-mens-morris-3d`.
3. Выберите тип репозитория **Public** (публичный — для бесплатного GitHub Pages) и нажмите **Create repository**.
4. На странице созданного репозитория нажмите ссылку **uploading an existing file** (или кнопку **Add file** → **Upload files**).
5. Распакуйте архив `Three_Mens_Morris_3D_iPhone_GitHub_Pages.zip` и перетащите **все файлы из него** (`index.html`, `manifest.json`, `sw.js`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `favicon.png`, `.nojekyll`) в окно загрузки GitHub.
6. Внизу страницы нажмите зеленую кнопку **Commit changes**.
7. Перейдите во вкладку **Settings** (в верхнем меню репозитория) → в левой колонке выберите раздел **Pages**.
8. В блоке **Build and deployment** → **Branch** выберите ветку `main` (или `master`), папку `/ (root)` и нажмите **Save**.
9. Подождите 30–60 секунд и обновите страницу — сверху появится ваша готовая ссылка вида:
   `https://vicrom1509.github.io/three-mens-morris-3d/`

## Шаг 2. Установка приложения на iPhone

1. Откройте полученную ссылку `https://vicrom1509.github.io/three-mens-morris-3d/` в браузере **Safari** на iPhone.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх в нижней панели Safari).
3. Прокрутите список чуть ниже и выберите пункт **«На экран „Домой“»** (*Add to Home Screen*).
4. Проверьте название **«Три Мельницы 3D»** с золотой иконкой доски и нажмите **«Добавить»** в правом верхнем углу.

Теперь на рабочем столе iPhone появится иконка игры. При нажатии на нее «Три Мельницы 3D» запускается **на весь экран без адресной строки и кнопок Safari**, как полноценное приложение.

## Шаг 3. Как играть по сети между Samsung S26 Ultra (APK) и iPhone (PWA)

1. Запустите игру на обоих телефонах (на S26 Ultra через установленный APK, на iPhone — с иконки на экране «Домой»).
2. Нажмите на круглую кнопку с **глобусом** в правом верхнем углу экрана игры.
3. На первом телефоне нажмите **«Создать код»** — появится 4-значный код комнаты (вы играете за Белых).
4. На втором телефоне введите этот 4-значный код и нажмите **«Войти»** (второй игрок играет за Чёрных).
