## Шаг 1. Установка приложения на iPhone

1. Откройте полученную ссылку `https://<ваш-логин>.github.io/three-mens-morris-3d/` в браузере **Safari** на iPhone.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх в нижней панели Safari).
3. Прокрутите список чуть ниже и выберите пункт **«На экран „Домой“»** (*Add to Home Screen*).
4. Проверьте название **«Три Мельницы 3D»** с золотой иконкой доски и нажмите **«Добавить»** в правом верхнем углу.

Теперь на рабочем столе iPhone появится иконка игры. При нажатии на нее «Три Мельницы 3D» запускается **на весь экран без адресной строки и кнопок Safari**, как полноценное приложение.

## Шаг 2. Как играть по сети между Samsung S26 Ultra (APK) и iPhone (PWA)

1. Запустите игру на обоих телефонах (на S26 Ultra через установленный APK, на iPhone — с иконки на экране «Домой»).
2. Нажмите на круглую кнопку с **глобусом** в правом верхнем углу экрана игры.
3. На первом телефоне нажмите **«Создать код»** — появится 4-значный код комнаты (вы играете за Белых).
4. На втором телефоне введите этот 4-значный код и нажмите **«Войти»** (второй игрок играет за Чёрных).
